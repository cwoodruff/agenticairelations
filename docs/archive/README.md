# Archive: version 1

These two documents describe version 1 of Agentic Developer Relations, from April 2026. They are kept as a record and are no longer maintained.

- `Agentic_Relations_Framework.docx`: the original framework document.
- `Agentic_Relations_Site_Plan.md`: the original site build plan and page copy.

Both contain claims that have since been corrected or withdrawn: a misquotation of Jeff Dean, an incorrect Amdahl figure, misreadings of the METR and Jellyfish studies, a pattern list that does not match the book, three new DevRel roles, and MCP tiers. See [`../agentic-devrel-critique.md`](../agentic-devrel-critique.md) for the review.

The current framework is [`../agentic-devrel-v2-vision.md`](../agentic-devrel-v2-vision.md). Do not write site copy from the files in this folder.
